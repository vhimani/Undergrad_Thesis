# Generated thesis outputs

`tables/` contains Tables 1–10 as CSV files. Tables 4–9 include raw estimates,
standard errors, p-values, and formatted cells. `regression-results.csv` and
`regression-results.dta` are the tidy model-level source for those tables.

`figures/` contains the six figures from the thesis in PDF and PNG formats:

1. Market Work
2. Market Work: January 2019–December 2020
3. Leisure
4. Nonmarket Work
5. Childcare
6. Quarterly Average of Market Hours

`validation/REPORT.md` summarizes the comparison with the submitted thesis;
`validation/descriptive-comparison.csv` and
`validation/regression-comparison.csv` contain the cell-level audit trails.

All files in this directory are regenerated by `make all`.
